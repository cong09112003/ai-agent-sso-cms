# React components (modules and shared components)

## Shape of a component
- Function components with a default export, PascalCase file name matching the component (`CustomerForm.js`, `GroupModal.js`). Feature folders use `index.js` for the list page, `<Entity>SavePage.js` (some older files use `SaveBase`/`Savebase`) for the edit page, and `<Entity>Form.js` for the form. Follow the spelling already used in the folder you are editing; don't rename existing files.
- Imports go through the `@` aliases (`@components/cms`, `@hooks/useListBase`, `@constants/apiConfig`). Use a relative import only for a sibling file in the same feature folder (`./CustomerForm`, `./routes`).
- Build on Ant Design 5 (`antd`) and the shared kit in `@components/cms` first: `PageWrapper`, `ListPage`, `BaseTable`, `BaseForm`, the `*Field` inputs, `BaseTooltip`, `HasPermission`. Don't add another UI or styling library.
- Icons come from `@ant-design/icons` (most common), `@tabler/icons-react`, or `react-icons`. All three are already installed.

## State and effects
- Derive values instead of copying props into state. Put values that change on every render into `useMemo` only when the computation is expensive; the codebase uses memoization sparingly and that is fine.
- `react-hooks/exhaustive-deps` is OFF in ESLint, so nothing warns you about stale closures. Before writing an effect, list its dependencies yourself. Existing effects often depend on `[dataDetail]` or `[isEditing]` only on purpose; keep that intent when you edit them.
- Clean up timers, listeners, and subscriptions in the effect's return function. `useFetch` already guards against setting state after unmount (`useIsMounted`).
- Lists: use a stable `key`/`rowKey` from the data (`record.id`), never the array index, unless the list is static.

## Text, i18n, styling
- User-visible text is Vietnamese by default. Write it through react-intl: `defineMessages({ key: 'Văn bản' })` at the top of the file, or `<FormattedMessage defaultMessage="..." />` inline. Ids are generated by `babel-plugin-react-intl-auto`, so don't add `id`. Reuse `commonMessage` from `@locales/intl` for generic labels. Format messages with `useTranslate()` (`translate.formatMessage`, `translate.formatKeys` for option arrays).
- Component styles go in a co-located `*.module.scss` (`import styles from './index.module.scss'`, camelCase class names). Global styles and SCSS variables/mixins live in `src/assets/scss`. Prefer Ant Design layout (`Row`/`Col`, `Flex`, `Card`) over custom CSS. Use inline `style` only for one-off tweaks, as the existing code does.
- Responsive layout: use Ant Design grid spans (`<Col xs={24} md={12}>`) instead of fixed widths.

## Accessibility
- Use real `<Button>`/`<a>` for actions, never a clickable `<div>`. Icon-only buttons need a `BaseTooltip` (as in action columns) or an `aria-label`.
- Form fields always get a `label` through the field components so Ant Design links the label to the input.
- Clickable table rows (`onRow` `onClick`) must also be reachable some other way, for example through the action column's edit button.

## Performance
- Don't add `React.memo`, `useCallback`, or `useMemo` everywhere. Add them where a measurable problem exists, for example in large tables or expensive column renderers.
- Import only what you use from `lodash` (`import debounce from 'lodash/debounce'`). Use `dayjs` for dates. `moment` is installed but unused, so don't introduce it.
